# Assets del informe

Las evidencias del informe se organizan por capítulo para mantener una trazabilidad clara entre el `README.md` y los artefactos visuales.

- `caratula/`: logo UPC y elementos de portada.
- `team/`: fotografías de integrantes usadas por las referencias actuales del informe.
- `chapter1/`: Lean UX y evidencia relacionada con Startup/Solution Profile.
- `chapter2/`: competidores, entrevistas, personas, journey maps, empathy maps y EventStorming.
- `chapter3/`: Impact Mapping y artefactos de Requirements Specification.
- `chapter4/`: style guide, IA, wireframes, mock-ups, prototipos, C4, class diagrams y database diagrams.
- `chapter5/`: GitFlow, Sprint 1, implementación, ejecución, servicios, despliegue y colaboración.

Usar nombres descriptivos en kebab-case y evitar archivos duplicados o temporales.
